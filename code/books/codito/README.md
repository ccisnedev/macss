# codito

The MACSS vocabulary and its diagrams, written to be understood on first
reading — the register of a children's book, deliberately.

This is not a shorter version of the `macss` book's glossary. It is a different
instrument for a different moment: what you hand someone on day one, before they
can hold the whole model in their head. The `macss` book defines terms for a
reader who has already accepted the architecture; codito has to make someone
want to.

The constraint runs the useful direction. A term that cannot be drawn, or cannot
be explained plainly, is usually a term that is not yet understood — so writing
this book is a test of the vocabulary, not merely a presentation of it.

## Layout

Identical to the `macss` book, and for the same reasons:

```
SUMMARY.md        reading order, shared by every language — slugs, not titles
diagrams/         Mermaid sources, shared
src/<lang>/       one directory per language, one file per slug
```
