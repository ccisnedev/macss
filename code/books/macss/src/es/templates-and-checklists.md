# Plantillas y checklists

Este capitulo concentra plantillas operativas para mantener consistencia editorial y tecnica.

## Checklist de capitulo tecnico

1. define concepto,
2. define regla operativa,
3. muestra ejemplo,
4. incluye anti-patron,
5. enlaza evidencia verificable.

## Checklist de cambio arquitectonico

1. ADR creado o actualizado,
2. contratos impactados identificados,
3. tests y gates actualizados,
4. riesgos y rollback definidos.

## Plantilla minima de ADR

```text
Titulo
Contexto
Decision
Consecuencias
Estado
Evidencia
```

## Checklist de paridad SDK

1. contrato funcional equivalente,
2. pruebas equivalentes,
3. observabilidad minima,
4. release validado.
