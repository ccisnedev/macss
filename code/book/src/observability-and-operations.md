# Observabilidad y operacion real

Operar MACSS en produccion requiere visibilidad continua de estado, trafico y errores.

## Pilares

1. Health checks para estado de servicio.
2. Logs estructurados para trazabilidad.
3. Metricas para capacidad, latencia y errores.
4. Alertas y runbooks para respuesta operativa.

## Minimo de produccion

1. endpoint de salud,
2. metricas exportables,
3. correlacion de logs por request,
4. politicas basicas de incidentes.

## Regla de calidad operativa

Si no se puede observar, no se puede operar con seguridad.
