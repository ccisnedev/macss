# Flujo de desarrollo estandar

El flujo de desarrollo MACSS es incremental, verificable y orientado a contratos.

## Ciclo diario

1. definir alcance del cambio,
2. mapear impacto por modulo,
3. implementar en slices verticales,
4. ejecutar gates,
5. abrir PR con evidencia,
6. merge y verificacion post-merge.

## Regla de ejecucion

No hay cambio completo sin evidencia de:

1. contrato,
2. pruebas,
3. impacto operativo.

## Integracion de herramientas

1. CLI companion para tareas de desarrollo.
2. modulo DevOps para automatizacion operativa.
3. CI/CD como validador de consistencia.
