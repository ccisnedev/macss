# MACSS Architecture Book

This directory contains the canonical architecture book for MACSS.

The book is maintained as Markdown so it can be:

- versioned in Git,
- reviewed with pull requests,
- rendered in site pipelines,
- consumed as source-of-truth by contributors and AI agents.

Editorial rule:

- Conceptual and explanatory chapters live in this book.
- Operational contracts remain in docs/spec.
- Decision history remains in docs/adr.

Start reading from SUMMARY.md.
