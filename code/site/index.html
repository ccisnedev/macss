macss

bend all four

Modular Architecture for Comprehensive Software Solutions

GitHub → Install CLI →

MACSS is a development methodology based on three principles: modular architecture, executable specification (tests and contracts as the source of truth), and closed loop (automated verification as the error sensor). A single developer holds complete context over every layer — no hand-offs, no silos. Every module can be extracted as a microservice without changing its internal architecture.

The four elements

Every MACSS module is a vertical slice that owns all four layers. The module boundary is explicit; its dependencies on other modules are declared.

db Earth

Persistence layer. SQL schemas and DDL scripts managed as Database as Code — no ORMs, no incremental migrations. The schema is the contract.

api Air

Business logic layer. Use cases with typed Input / Output DTOs and a validate() + execute() lifecycle. CQRS split: REST for commands, GraphQL for queries.

modular_api →
ui Water

Presentation layer. Controllers, services, views. Consumes the API through a transport-agnostic client with the Result pattern — no raw HTTP in the UI.

service_client →
infra Fire

Deployment and operations. CI pipelines, containers, environment config. The layer that builds, ships and destroys on demand.

Modules

A module groups related use cases from the same business domain — clients, billing, inventory. Each module is a vertical cut across all four layers:

module clients/
├── db/    → DDL scripts, repositories
├── api/   → use cases, endpoints
├── ui/    → service, controller, views
└── infra/ → module-specific config

If a module grows large enough, it can be extracted as a microservice — the internal architecture does not change. The boundary was always there.

CLI

macss scaffolds the structure so you can focus on the domain. Install once, create projects instantly.

PowerShell irm https://macss.ccisne.dev/install.ps1 | iex

Installs to %LOCALAPPDATA%\macss\, adds macss and alias ma to PATH.

Bash curl -fsSL https://macss.ccisne.dev/install.sh | bash

Installs to ~/.macss/, adds macss and alias ma to PATH.

macss create <path>

Scaffold a new MACSS project — creates code/{db,api,ui,infra} and doc templates.

macss doctor

Verify local installation and asset integrity.

macss upgrade

Download and apply the latest release from GitHub.

macss version

Print the current CLI version.
